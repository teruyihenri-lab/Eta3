# Hapat e ardhshëm

> Eta3 · dokumentacioni në shqip · krijuar më 2026-11-07 · dega `localization/albanian-sq`

## Hapat me përparësi
1. Plotëso `values-sq/strings.xml` me të gjitha string-et e shfaqura në `values/strings.xml`, duke mbajtur parametrat dhe escape XML të saktë.
2. Verifiko që të gjitha string-et hardcoded të Kotlin dhe XML të përdorin shqipen në UI, zë, njoftime dhe aksesueshmëri.
3. Kontrollo ndërtimin e app-it dhe testet Gradle në një mjedis me Java 25 / Android SDK të konfiguruar.
4. Rishiko ekranet në telefon dhe korrigjo çdo pasaktësi të lokalizimit përpara bashkimin në `main`.
5. Përditëso `AI_CHANGES.md`, `CURRENT_STATUS.md`, `NEXT_STEPS.md` dhe `TEST_RESULTS.md` bashkë me çdo ndryshim të ri.
